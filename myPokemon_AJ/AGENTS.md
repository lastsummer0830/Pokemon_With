# myPokemon_AJ — 게임 개발 규칙

## 권위와 안전
- 사용자 최신 지시와 저장소 루트 `.hermes.md`가 이 파일보다 우선한다.
- 현재 코드·`package.json`·실행 결과를 과거 문서·memory·주석보다 신뢰한다.
- 사용자 변경을 보존하고 요청 밖 리팩터링을 하지 않는다. reset·restore·clean·덮어쓰기를 하지 않는다.
- 삭제, 대량 이동·이름변경, 패키지 설치, commit, push, 배포는 사용자 승인 후 한다.
- 완료를 말하기 전에 관련 빌드와 실제 게임 화면을 검증한다. 실행하지 못하면 `미검증`과 이유를 남긴다.

## Claude 개발 책임
- Claude는 편집 전에 관련 코드·Git 상태·현재 실행 경로를 조사하고, Hermes 계약의 목표·파일 범위·acceptance에 맞는 구현안을 세운다.
- 관련 프로젝트 Skill과 조건부 rule을 로드한 뒤 구현하고, 허용된 도구로 테스트·build·실제 게임 흐름을 자체 검증한다.
- 공식 `/run`, `/verify`, `/code-review`, `/debug`를 사용할 수 있으나, 프로젝트의 입력·renderer·scene·console acceptance를 생략하는 근거가 아니다.
- 변경 파일·설계 이유·실행 증거·남은 위험과 미검증 항목을 Hermes에 보고한다. Hermes가 같은 증거를 독립 확인하기 전에는 완료가 아니다.

## 게임의 정체성
- Phaser 3·TypeScript·Vite 기반 2D 탑다운 픽셀 RPG다.
- 핵심 차별점은 집 꾸미기와 포켓몬 컨디션을 배틀에 연결하는 것이다.
- 인게임 화풍은 픽셀 전용이다. 매끈한 일러스트를 인게임 에셋으로 쓰거나 사용자 에셋을 임의 교체하지 않는다.
- 남자 주인공은 RED, 여자 주인공은 DAWN, 라이벌은 Nemona다.
- 캐릭터 이름은 본인의 첫 자기소개부터 표시하고 그 전에는 `???`로 둔다. 일반 NPC는 처음부터 이름을 표시할 수 있다.
- 화자 대사는 이름창을 쓰고 나레이션은 이름창 없이 표시한다. 기존 사용자 대사는 요청 없이 바꾸지 않는다.
- 인트로는 성별 선택 후 이름 입력 순서다.
- 플레이 난이도는 노말 하나뿐이다. 기존 난이도 타입·세이브 필드는 호환성을 위해 유지하되 선택 화면을 다시 만들지 않는다.

## 실제 실행 기준
- 명령은 `package.json`의 현재 scripts를 기준으로 한다.
- 개발 서버는 `npm run dev`, 고정 주소는 `http://localhost:5180`이다.
- 웹 빌드는 `npm run build`; Electron 개발 실행은 `npm run app`; 기존 Windows 실행본 갱신은 필요할 때 `npm run app:bake`다.
- 코드 변경은 빌드만으로 끝내지 않는다. 맵·충돌·UI·에셋·애니메이션은 실제 플레이 또는 캡처로 확인한다.
- 이 디렉터리에서 Claude Code를 시작하면 대화형은 `/add-dir ..`, 단발 실행은 `--add-dir ..`로 저장소 상위를 추가한 뒤 루트 `.claude/.verify` 캡처를 읽는다.
- 새 scene이나 확인이 어려운 연출은 `DebugMenuScene`과 `src/data/debugChecks.ts`를 이용해 바로 재현 가능하게 만든다.

## 에셋·UI·맵
- 정적 런타임 에셋은 `public/assets/`에 두고 코드에서는 `assets/...` 상대 경로로 로드한다.
- 사용자가 후보를 고르는 작업은 실제 후보와 비교 이미지를 `01_Resources/Pick/<카테고리>/`에 둔다. 자동 검증 원본 위치와 섞지 않는다.
- UI look이 갈리면 임의 확정하지 말고 2~3개 실제 렌더 후보를 제시해 사용자가 고르게 한다.
- 맵 충돌 좌표를 화면 눈대중으로 입력하지 않는다. 원본 이미지의 격자·좌표와 실제 이동 결과를 함께 검증한다.
- 픽셀 텍스처에는 필요한 위치에서 `NEAREST` 필터를 적용한다.

## 조건부 절차
- `.claude/rules/run-build.md`, `maps-collision.md`, `assets.md`, `game-ui.md`는 해당 경로 작업 때만 참고하는 세부 체크리스트다.
- `.claude/skills/**`는 자동 상시 규칙이 아니다. 현재 작업에 맞고 실제 코드와 대조된 Skill만 명시적으로 사용한다.
- 현재 진행상태, PC별 절대경로, 일회성 해결 기록은 이 파일에 고정하지 않는다.
