## 1. 언덕(점프대) — 원본 규칙 그대로 이식

### 원본 규칙 (Scripts.rxdata에서 뽑은 루비 원문으로 확인)
- `TerrainTag.rb`: **지형태그 1 = `:Ledge`**
- 1번도로 언덕 타일 3종(ID 1194·1198·1212) 전부 **`passage = 0x07`** = 아래·좌·우 막힘, **위쪽만 열림**
- `Game_Character#passable?`가 목적지를 **반대방향(10−d)**으로 검사 →
  **위→아래만 통과**, 아래→위·옆→옆은 막힘
- `Game_Player#move_generic`: 목적지가 ledge면 걷는 대신 **`jumpForward(2)` = 2칸 점프** + `pbSEPlay("Player jump")`
- `Game_Character#jump`: 시간 = jump_speed 3의 0.25초 × 2칸 = **0.5초**, 높이 = `2 × 32 × 3/8` = **0.75칸**,
  곡선 = `jump_peak × (4·|f−0.5|² − 1)`

## 2. VS 연출 — AR HGSS `VSTrainer` 이식

### 원본이 이 그림들을 쓰는 방식
- `Overworld_BattleIntroAnim.rb`: **`hgss_vs_<타입>` + `hgss_vsBar_<타입>` 두 그림이 다 있는 1:1 트레이너전**에만 발동(우선순위 60). 없으면 기본 볼 전환.
- 초상이 있는 상대 = **관장 19 + 챔피언 그린 + 로켓보스 = 21종뿐** → 잡트레이너는 자동으로 평범한 전환.
- `Transitions.rb`의 `Transitions::VSTrainer` = **4.0초** 상태 기계.

### 타이밍(원본 `set_up_timings` 그대로)
```
0.0~0.2  띠가 오른쪽→왼쪽 지그재그로 깔림(BAR_MASK 16단계)
0.7~1.1  VS 로고 잔상이 2.0배에서 줄며 등장 → 본체로 교체
1.25~1.4 상대가 **검은 실루엣**으로 오른쪽에서 슬라이드(384까지 왔다가 428로 톡)
1.9      흰 플래시 — 절반 지점에서 색이 들어오고 이름이 뜸, 뒤 배경 어두워짐(224/255)
3.0~3.5  화이트아웃 → 3.8~4.0 블랙아웃 → 배틀
```

### 우리 쪽
- **`src/systems/vsIntro.ts` (신규)** — 위 타이밍·좌표를 그대로. 가상좌표 512×384(배틀 화면과 같은 방식).
- 붙인 곳: `GymScene`(그린) · `WorldScene`(라이벌 네모 + 일반 트레이너전 — **초상 있는 상대만**).
- **`tools/ar-vs/extract-vs.py` (신규)** — 에셋 추출.
  ⭐ 실측: **`hgss_vsBar_*` 21장이 픽셀까지 전부 동일** → 띠는 공용 1장. `black_half.png`는 순수 검정 단색이라 사각형으로 대체.
- 원본처럼 **전환이 시작될 때 배틀 BGM을 켠다**(playBgm은 같은 곡이면 no-op이라 BattleScene이 다시 불러도 안 끊김).
- 우리 HUD("방향키: 이동")는 원본에 없는 것이라 연출 중 감춘다.

## 3. 세이브 슬롯 — 원본 `Auto Multi Save`와 같은 구성

- **자동세이브 3칸 + 세이브 A~H 8칸 = 11칸** (원본 플러그인의 슬롯 이름 그대로)
- **옛 1칸 저장(`myPokemon.save`)은 첫 실행에 '세이브 A'로 자동 이관** — 원본도 옛 Game.rxdata를 첫 수동칸으로 옮긴다
- 자동저장은 **자동 3칸을 돌아가며** 쓰고 **수동 칸을 안 덮는다.** '마지막 칸' 표시도 안 건드린다
  (안 그러면 다음 수동 저장이 엉뚱한 칸에 간다)
- **플레이 시간 신규**(`playSeconds`) — 원본 로드화면의 `Time`과 같은 자리. 이어하면 그 칸의 시간부터 이어 센다
- **`src/scenes/SaveSlotScene.ts` (신규)** — 이어하기와 인게임 '저장'이 같은 화면을 쓴다. 칸마다 이름·배지 수·플레이 시간·저장 날짜
- 세이브 버전 **v4 → v5**

### 원본에 있는데 **일부러 뺀 것 3가지** (이유는 `settings.ts` 머리말)
- 박스 자동전송 → **박스 시스템 자체가 없음**
- 별명 주기 → 잡을 때 별명 짓는 흐름이 없음
- 대화창/메뉴 스킨 → 우리 UI는 windowskin 그림이 아니라 코드로 그림

동작 안 하는 토글을 두면 "고장난 옵션"이 되므로 넣지 않았다. **그 기능이 생기면 그때 추가할 것.**

### 난이도 = 노말 하나로 확정 (사용자 지시)
원본은 시작할 때 5개(이지/노말/하드/익스트림/인새인) 중 고르게 한다(Map072 이벤트).
**우리는 선택 화면을 만들지 않는다.** `systems/difficulty.ts`의 5종 표와 세이브 필드는 유지
(원본 실측 근거 + 세이브 호환). **"선택 화면이 없네?" 하고 다시 만들지 말 것** — AGENTS.md §1.5에도 박음.

원본 대조로 확인한 매핑(Map072가 변수 51에 넣는 값 ↔ 플러그인):
`이지=1(-4/0) · 노말=5(-3/+0~2) · 하드=3(0/0) · 익스트림=2(+1/+0~2) · 인새인=6(+3/+0~2)`
⚠️ 플러그인 소스 주석은 뒤죽박죽이다(index2에 "Medium", index5에 "HARD"). **이벤트가 넣는 값이 정본.**

## 7. 함정 (이번에 걸린 것)

1. **키를 누른 채로 두면 `moving`이 프레임 사이에 절대 false로 안 보인다** — 착지시킨 그 update가 곧바로 다음 걸음을 시작한다. 바깥에서 폴링하면 착지칸을 놓친다 → **도착 처리(landOn)를 가로채서** 잡을 것.
2. **씬을 다시 시작해도 Phaser는 같은 인스턴스를 쓴다** → 지난 검증에서 붙인 훅이 살아남아 새 씬을 즉시 얼렸다. 시작 전에 떼어낼 것.
3. **원본 연출은 매 프레임 도는 상태 기계다** — 시각을 껑충 뛰면 그 사이 전환을 통째로 건너뛴다. 검증도 16ms씩 굴릴 것.
4. **⭐ 숫자는 맞는데 화면엔 안 그려지는 버그** — 사각형을 `fillAlpha 0`으로 만들고 오브젝트 alpha만 올렸다. 검사는 통과하는데 화이트아웃이 안 보였다. **캡처 밝기(59→176)로 잡았다.** 도형은 `fillAlpha 1`로 만들고 `setAlpha`로 껐다 켤 것.
5. **캡처는 렌더를 기다렸다 찍을 것** — 시각을 민 직후에 찍으면 이전 프레임이 찍힌다(headless ~3fps). 씬 진입 fadeIn(400ms)도 기다려야 한다(안 그러면 시커멓게 찍혀 "밤인가?" 오해).
6. **headless에서 키를 연달아 보내면 이벤트가 씹힌다** → 사이를 250ms 띄울 것.
7. **비정수 확대는 도트 격자를 깨뜨린다**(1.8배로 확대했다가 겪음). **1배 아니면 2배.**
8. **전수로 세기 전엔 단정하지 말 것** — 대문자 파일명으로 포켓몬을 거르다 `NPC 01`이 섞여 결론이 틀렸다. `species.json`의 종족 id로 다시 세서 바로잡았다.
